# M3 Remaining Work and M4 Roadmap

## Before staging sign-off (priority order)
1. Native Worker/D1 tests on Windows or compatible CI, plus full authenticated browser E2E for Lead/Co-Lead/Executive/Member.
2. Rehearse 0006 and notification table rebuild 0007 against an approved isolated D1 staging copy; verify backup and restoration.
3. Confirm the Event CBL's adoption status, delegation authority, document classification/records custodian and SOP templates with DSC governance.
4. Validate WCAG 2.2 AA, dialog focus trapping, light/dark contrast, 200% zoom and keyboard-only navigation across the integrated site.
5. Test realistic M3 notification volumes on Cloudflare D1, and address future queuing when batch limits are reached.
6. Add event requirement template catalog after SOP approval; consider event-team ownership/permissions for record categories.
7. Harden announcement linked-project visibility with full resource-permission checks rather than conservative redaction alone.

## M4 or later
- Registration forms and participant management, with appropriate privacy governance.
- Attendance/check-in and certificates.
- Event finance approval requests, receipts, independent audit and treasury controls; no temporary role bypass.
- Private R2 uploads and records handover to permanent custodians.
- Post-event survey/feedback, dashboards and long-term analytics.
- Scheduled announcements and controlled public communications if formally approved.
