## Reproduction

Run the existing local launcher from the application root with its synthetic Lead account. It preserves `.qa-state`; do not reinstall dependencies while the server is running.

```powershell
powershell.exe -NoProfile -File scripts/Start-Local.ps1
```

In another PowerShell window at the same app root:

```powershell
.qa-venv\Scripts\python.exe test/ui_polish_browser.py --phase after
$env:CHROMIUM_PATH = 'C:\path\to\full\chromium\chrome.exe'
.qa-venv\Scripts\python.exe test/ui_polish_interactions.py
.qa-venv\Scripts\python.exe scripts/validate_release.py --native --browser
```

Use full Chromium, rather than the headless-shell executable, for native zoom. `test/requirements-qa.txt` supplies the existing QA dependencies. The interaction suite uses separate profiles under `dist/ui-polish/`; it does not change the user's browser preferences. Before-zoom reproduction requires the preserved `baseline-source/public/` snapshot supplied in the evidence ZIP.
